This agent never sleeps. It watches the bounty board around the clock, sharp-eyed in the dark, hunting for the next entry while everyone else is asleep — and it does it with a sense of humour. The owl says all of that at a glance: night work, sharp sight, quiet vigilance, and a playful edge. No robot, no smiley — the obvious picks say nothing about how this agent actually works.
